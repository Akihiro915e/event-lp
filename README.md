## 🚀 デプロイ手順（Vercel）

### 方法: GitHub経由での自動デプロイ（推奨）

1. 本リポジトリを GitHub にプッシュします。
2. [Vercel](https://vercel.com/) にログインし、「**Add New...**」 > 「**Project**」を選択します。
3. GitHub アカウントを連携し、本リポジトリ（`event-lp`）を選択して「**Import**」をクリックします。
4. 設定はすべて自動検出されるため、そのまま「**Deploy**」ボタンをクリックします。
5. 数十秒で全世界にCDN配信されるURL（`https://event-lp-xxxx.vercel.app`）が発行されます！
   ※ 以降、GitHub の `main` ブランチにコミットをプッシュするたびに自動で更新デプロイされます。
